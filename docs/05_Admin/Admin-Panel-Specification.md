# Admin Panel Specification

## Overview

The admin panel provides professional management capabilities for Beyraghe Mandegar.

## Modules

- Dashboard
- Show Management
- Performance Management
- Venue Management
- Reservation Management
- Ticket Management
- Check-in Management
- Content Management
- Reports
- Settings

## Sales Control

Administrators can:

- Open sales
- Close sales
- Define sale windows
- Define purchase limits
- Monitor capacity
