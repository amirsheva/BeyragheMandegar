# Feature Catalog

## Overview

This document defines the main product capabilities of Beyraghe Mandegar.

The platform is designed as an event management and digital ticketing system for an artistic group.

---

# Core Modules

## 1. Public Website

### Description

A public-facing Persian-first website for audiences.

### Features

- Upcoming performances
- Past performances archive
- Artistic group news
- Gallery
- Performance details
- Venue information
- Navigation links

---

# 2. Show Management

## Description

Management of artistic works.

### Features

- Create show
- Edit show information
- Manage description
- Manage posters
- Manage gallery
- Archive completed shows

---

# 3. Performance Management

## Description

A performance represents a specific execution of a show.

### Features

- Create performance
- Assign venue
- Define date and time
- Configure capacity
- Open/close sales
- Manage performance status

---

# 4. Venue Management
