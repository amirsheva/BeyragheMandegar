# User Stories

## Actors

The main actors are:

- Customer
- Administrator
- Event Operator

---

# Customer Stories

## Authentication

As a customer,

I want to verify my mobile number using OTP,

so that I can access my profile securely.

---

## Reservation

As a customer,

I want to reserve tickets for a performance,

so that I can attend the event.

---

## Ticket Access

As a customer,

I want to see my tickets in my profile,

so that I can manage my reservations.

---

## Ticket Sharing

As a customer,

I want to share my ticket,

so that another person can access the information.

---

## Navigation

As a customer,

I want to open the venue location,

so that I can easily reach the performance location.

---

# Administrator Stories

## Manage Shows

As an administrator,

I want to create and manage shows,

so that artistic works can be presented online.

---

## Manage Performances

As an administrator,

I want to define multiple performances for a show,

so that different halls and dates can be managed.

---

## Control Sales

As an administrator,

I want to define ticket sales start and end times,

so that ticket availability is controlled.

---

## Monitor Reservations

As an administrator,

I want to see reservation status,

so that I can understand sales performance.

---

# Event Operator Stories

## Check-in

As an event operator,

I want to scan QR tickets,

so that audience entry can be verified quickly.

---

## Offline Validation

As an event operator,

I want ticket validation to work offline,

so that entrance operations continue without internet access.
