# Customer Journey

## Overview
This document defines the audience experience journey.

## Discovery
Users can discover:
- Upcoming performances
- Show information
- Venue details
- News and archive

## Reservation Flow
Open Website -> Select Show -> Select Performance -> Enter Mobile -> OTP Verification -> Profile -> Reservation -> Ticket

## Customer Profile
Users can:
- View reservations
- View tickets
- Print tickets
- Share tickets
- Access history

## Venue Experience
Navigation support:
- Google Maps
- Neshan
- Waze
