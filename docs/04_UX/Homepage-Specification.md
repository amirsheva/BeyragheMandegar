# Homepage Specification

## Hero Section

Purpose:
Create emotional connection.

Contains:

- Main show poster
- Show title
- Short description
- Reservation CTA
- Countdown timer

## Upcoming Performances

Each card contains:

- Show name
- Date
- Venue
- Remaining capacity
- Reservation button

## Artistic Identity Section

Contains:

- Group introduction
- History
- Creative vision

## Archive Section

Past performances:

- Poster
- Gallery
- Description
- Reviews
