🎭 بیرق ماندگار (Beyragh Mandegar)

پروژه‌ی بیرق ماندگار یک سامانه مدیریت اجرا و رزرو آنلاین است که با React + Vite در سمت کاربر و Node.js + AdminJS + SQLite در سمت سرور توسعه داده شده است.

✨ ویژگی‌ها
	•	مدیریت اجراها و سانس‌ها
	•	ثبت رزرو آنلاین با بررسی ظرفیت
	•	پنل مدیریت با تم Dark Mode و زبان فارسی
	•	داشبورد آماری هوشمند
	•	ساخت خودکار سانس‌های بعدی

⚙️ تکنولوژی‌ها
	•	Frontend: React, Vite, TailwindCSS
	•	Backend: Node.js, Express, Sequelize, AdminJS
	•	Database: SQLite
	•	Deployment: GitHub Pages + Render (در صورت نیاز)

⸻

🎭 Beyragh Mandegar

Beyragh Mandegar is an online show management and booking system built with
React + Vite on the frontend and Node.js + AdminJS + SQLite on the backend.

✨ Features
	•	Manage shows and schedules
	•	Online booking with capacity control
	•	Admin panel with Persian UI and Dark Mode
	•	Dynamic dashboard with real-time stats
	•	Automatic schedule generation

⚙️ Tech Stack
	•	Frontend: React, Vite, TailwindCSS
	•	Backend: Node.js, Express, Sequelize, AdminJS
	•	Database: SQLite
	•	Deployment: GitHub Pages + Render (optional)
